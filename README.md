DayTrack – Your Simple Daily Task Manager

DayTrack is an Android productivity application designed to help users organise their daily activities and manage tasks easily.

Features

- Add new tasks.
- Delete completed or unwanted tasks.
- Simple and user-friendly interface.
- Lightweight Android application.

Technology Used

- MIT App Inventor
- Android

Project Purpose

This project was developed to explore mobile application development and create a simple tool for everyday productivity.

Developer

Created as an independent beginner mobile app development project.

Platform

Android
